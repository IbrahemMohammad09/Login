# Login Interface

A compact React interface project built with Vite. The current app renders a single component from `src/Components/Delete`, providing a focused base for a login-related UI experiment.

## Tech stack
- React 18
- Vite
- Tailwind CSS
- React Icons

## Getting started
```bash
git clone https://github.com/IbrahemMohammad09/Login.git
cd Login
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Available scripts
- `npm run dev` — start the development server.
- `npm run build` — build the production assets.
- `npm run preview` — preview a production build.
- `npm run lint` — run ESLint.

## Project structure
- `src/App.jsx` — app entry component.
- `src/Components/Delete/` — the component currently rendered by the app.
- `src/index.css` and `tailwind.config.js` — global styles and Tailwind setup.
